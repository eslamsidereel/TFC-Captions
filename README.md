# TFC Captions

Releases for **TFC Captions** — an After Effects panel that transcribes a
composition locally, cuts and styles captions, animates them per character,
and uses AI to suggest where the highlights and b-roll belong.

The extension is distributed as a signed ZXP. **The source is not published
here** — this repository exists so the panel can check for updates, which it
does by reading the latest release tag.

## Installing

Download the `.zxp` from the latest release and install it with
[ZXP Installer](https://zxpinstaller.com/) or Adobe's UPIA. Restart After
Effects, then **Window → Extensions → TFC Captions**.

Access is granted through Lereve Portal; there is no licence key.
